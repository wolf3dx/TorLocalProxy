# Установка TorLocalProxy на iPhone и iPad

Apple не разрешает ставить приложения мимо App Store без подписи. Платной
учётной записи разработчика (99 $ в год) у проекта нет, поэтому приложение
подписывается **вашим собственным бесплатным Apple ID**. Способа обойтись
совсем без денег и без стороннего установщика не существует — это
ограничение Apple, а не недоделка приложения.

Ниже три способа, от удобного к простому.

---

## Способ 1 — AltStore: установка и автообновления

Компьютер нужен один раз, чтобы поставить сам AltStore. Дальше телефон
работает сам.

### 1. Поставить AltServer на компьютер

Скачайте с **altstore.io** (есть версии под Windows и macOS), установите и
запустите — программа живёт значком у часов.

На Windows дополнительно нужны **iTunes** и **iCloud** именно с сайта Apple,
а не из Microsoft Store: через них AltServer разговаривает с телефоном.

### 2. Поставить AltStore на iPhone

1. Подключите iPhone кабелем и разрешите на телефоне «Доверять этому
   компьютеру».
2. Значок AltServer → **Install AltStore** → выберите свой iPhone.
3. Введите **Apple ID и пароль**.

Пароль уходит напрямую Apple — это её штатный механизм подписи. Ни
разработчику, ни в приложение он не попадает. Если так спокойнее, заведите
для этого отдельный Apple ID.

### 3. Доверить сертификат

На iPhone: **Настройки → Основные → VPN и управление устройством** →
выберите свой Apple ID → **Доверять**.

### 4. Добавить источник

В AltStore на телефоне: **Browse → Sources → «+»** и вставьте ссылку:

```
https://github.com/wolf3dx/TorLocalProxy/releases/download/altstore/apps.json
```

### 5. Установить

В добавленном источнике появится **TorLocalProxy** — нажмите **Install**.
Готово.

Новые версии приходят сами: они появятся в разделе **My Apps → Updates**.

### Про семь дней

Бесплатная подпись Apple живёт неделю. AltStore продлевает её сам, но ему
нужен **включённый AltServer на компьютере в той же сети Wi-Fi** — достаточно
включать раз в неделю. Если компьютер не включать дольше, приложение
перестанет открываться. Данные при этом не теряются: хватит **My Apps →
Refresh**.

---

## Способ 2 — SideStore: потом совсем без компьютера

SideStore — ответвление AltStore, которое продлевает подпись **прямо на
телефоне**. Первая настройка сложнее: pairing-файл всё равно делается с
компьютера один раз, плюс включается локальный VPN-профиль. Зато дальше
компьютер не нужен вовсе.

Источник тот же — та же ссылка на `apps.json`.

---

## Способ 3 — Sideloadly: вручную, без магазина

1. Скачайте `.ipa` из раздела выпусков:
   `https://github.com/wolf3dx/TorLocalProxy/releases` → метка **ios-v0.0.7**.
2. На компьютере откройте **Sideloadly** (sideloadly.io), перетащите в него
   файл `.ipa`, введите Apple ID и нажмите **Start**.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   **Доверять**.

Повторять каждые семь дней. Обновления сами не придут — в этом и разница с
первым способом.

---

## После установки

Запустите приложение, при необходимости вставьте мосты и нажмите
**Подключить**. Поднимаются два прокси:

| Прокси | Адрес |
|---|---|
| SOCKS5 | `127.0.0.1:9050` |
| HTTP | `127.0.0.1:8118` |

Чтобы пропустить через Tor весь трафик Wi-Fi: **Настройки → Wi-Fi → «i» у
своей сети → HTTP-прокси → Вручную**, сервер `127.0.0.1`, порт `8118`.
SOCKS в настройках Wi-Fi у iOS нет — ради этого случая и сделан HTTP-прокси.

Кнопка **«Проверить IP»** спрашивает у check.torproject.org, кто вы снаружи,
и идёт туда через сам прокси: это доказательство, что трафик действительно
уходит через Tor.

В фоне приложение держится беззвучным звуком — иначе iOS усыпляет его и
прокси замолкает. Если система всё же выгрузила приложение, просто откройте
его снова.
