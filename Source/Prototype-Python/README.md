# Tor Local Proxy

Кросс-платформенное мини-приложение: поднимает подключение к луковой сети
через **мосты** и отдаёт наружу **локальный прокси**. То же, что делает Tor
Browser при подключении, но без браузера — только прокси.

```
   мосты из письма
   bridges@torproject.org
            │
            ▼
   ┌──────────────────┐   запускает   ┌─────────┐  obfs4/webtunnel  ┌────────┐
   │ Tor Local Proxy  │──────────────►│   tor   │──────────────────►│  сеть  │
   └──────────────────┘               └─────────┘   snowflake/meek  │  Tor   │
       │         │                         │                        └────────┘
       │         │                         └─ SOCKS5 127.0.0.1:9052
       │         └─ HTTP-прокси 127.0.0.1:8080
       ▼
   ваши программы
```

Приложение само пишет `torrc`, запускает процесс `tor`, поднимает pluggable
transports для ваших мостов, показывает прогресс подключения (0–100 %) и
держит два локальных адреса: SOCKS5 самого Tor и HTTP-прокси поверх него —
для программ, которые SOCKS5 не понимают.

**Функционала браузера нет** и не предполагается: ни окна просмотра, ни
профилей, ни защиты от отпечатков.

---

## Что нужно один раз поставить

Приложение — это управляющая обвязка; сам `tor` и программы транспортов
(`lyrebird`, `snowflake-client`, `webtunnel-client`) в комплект не входят.
Они берутся из официального **Tor Expert Bundle**.

1. Откройте <https://www.torproject.org/download/tor/> и скачайте Expert
   Bundle для своей системы.
2. Распакуйте архив и положите его содержимое в папку `tor` рядом с `run.py`:

```
Cowork/
├── run.py
├── tornode/
└── tor/
    ├── tor                 (tor.exe в Windows)
    ├── lyrebird            обслуживает obfs4, meek_lite, obfs3
    ├── snowflake-client    обслуживает snowflake
    └── webtunnel-client    обслуживает webtunnel
```

Приложение также само найдёт Tor, если у вас уже установлен **Tor Browser**
или системный пакет `tor` (`apt install tor`, `brew install tor`). Проверить:

```bash
python run.py --find-tor
```

> Транспорты нужны только под те мосты, которые вы используете. Для обычных
> мостов без транспорта (просто `IP:порт отпечаток`) достаточно одного `tor`.

## Как получить мосты

**Почтой** — работает даже там, где сайт Tor заблокирован. С адреса Gmail,
Riseup или Outlook отправьте пустое письмо на:

```
bridges@torproject.org
```

В теле письма напишите `get transport obfs4` (или `get transport webtunnel`).
В ответ придут строки вида:

```
obfs4 192.0.2.1:9443 8AF3C1E2...B21 cert=hK8sPq9v... iat-mode=0
obfs4 198.51.100.7:443 5C2D9F1A...E44 cert=Tz3nR7Ku... iat-mode=0
```

**Через сайт** (если он открывается): <https://bridges.torproject.org/>
— кнопка в приложении «Где взять мосты» ведёт туда же.

**В Telegram:** бот `@GetBridgesBot`.

Скопируйте всё письмо целиком и вставьте в приложение — приветствие,
подпись и прочую прозу оно пропустит само, разберёт только строки мостов.

## Запуск

```bash
python run.py                    # окно приложения
python run.py --no-gui --check   # без окна, с проверкой выходного IP
python run.py --help             # все параметры
```

Порядок в окне: вставили мосты → **Подключиться** → ждёте, пока полоса дойдёт
до 100 % → внизу появятся адреса прокси.

Мосты и настройки сохраняются между запусками:

- Windows — `%LOCALAPPDATA%\TorLocalProxy\`
- macOS и Linux — `~/.torlocalproxy/`

Там же лежат сгенерированный `torrc` и `tor.log` — первое, куда смотреть,
если что-то не подключается.

### Параметры командной строки

| Ключ | Что делает |
|---|---|
| `--no-gui` | работать без окна |
| `--bridges-file ФАЙЛ` | взять мосты из файла |
| `--no-bridges` | подключаться напрямую, без мостов |
| `--http-port N` | порт локального HTTP-прокси (по умолчанию 8080) |
| `--socks-port N` | порт SOCKS5 (по умолчанию 9052; `0` — выбрать свободный) |
| `--tor-binary ПУТЬ` | указать `tor` вручную |
| `--timeout СЕК` | сколько ждать подключения (по умолчанию 180) |
| `--check` | после подключения проверить выходной IP |
| `--print-torrc` | показать сгенерированный `torrc` и выйти |
| `--find-tor` | показать найденный путь к `tor` и выйти |

## Как направить программы в прокси

Два адреса делают одно и то же, выбирайте по тому, что умеет программа.

**SOCKS5 `127.0.0.1:9052`** — предпочтительно. Так работает Tor Browser.

**HTTP `127.0.0.1:8080`** — для программ, которые SOCKS5 не понимают.

```bash
# curl, pip, git, npm и большинство CLI
export HTTP_PROXY=http://127.0.0.1:8080
export HTTPS_PROXY=http://127.0.0.1:8080
curl -x http://127.0.0.1:8080 https://check.torproject.org/api/ip

# или напрямую через SOCKS5
curl --socks5-hostname 127.0.0.1:9052 https://check.torproject.org/api/ip
```

Windows: Параметры → Сеть и Интернет → Прокси → адрес `127.0.0.1`, порт `8080`.

Firefox: Настройки → Параметры сети → Ручная настройка → SOCKS v5
`127.0.0.1:9052`, отметить «Отправлять DNS-запросы через прокси».

Chrome: `chrome --proxy-server="socks5://127.0.0.1:9052"`.

Обязательно нажмите **Проверить IP** после подключения — приложение прогонит
запрос через всю цепочку и покажет, что видит внешний сайт.

## Поддерживаемые типы мостов

| Транспорт | Чем обслуживается | Когда применяют |
|---|---|---|
| `obfs4` | `lyrebird` | основной вариант, маскирует трафик под случайный шум |
| `webtunnel` | `webtunnel-client` | трафик выглядит как обычный HTTPS к сайту |
| `snowflake` | `snowflake-client` | через добровольцев-посредников, адрес заранее не нужен |
| `meek_lite` | `lyrebird` | через CDN крупных облаков |
| `obfs3`, `scramblesuit` | `lyrebird` | устаревшие |
| `conjure` | `conjure-client` | экспериментальный |
| без транспорта | не нужно | обычный мост `IP:порт отпечаток` |

Если для вашего моста нет нужной программы, приложение скажет об этом до
запуска и назовёт недостающий файл.

## Устройство

| Файл | Ответственность |
|---|---|
| `run.py` | точка входа |
| `tornode/bridges.py` | разбор и проверка строк мостов |
| `tornode/tormgr.py` | поиск бинарников, генерация `torrc`, процесс `tor`, bootstrap |
| `tornode/control.py` | control-протокол Tor: cookie/SAFECOOKIE, события, NEWNYM |
| `tornode/httpbridge.py` | HTTP-прокси поверх SOCKS5 |
| `tornode/app.py` | связка всего вместе, настройки, проверка IP |
| `tornode/gui.py` | окно |
| `tornode/cli.py` | разбор аргументов, консольный режим |
| `tests/` | тесты, включая фиктивный `tor` для сквозной проверки |

Зависимостей нет — только стандартная библиотека Python 3.8+.

### Тесты

```bash
python -m unittest discover -s tests -v
```

34 теста: разбор мостов и писем, генерация `torrc`, полный цикл запуска с
подставным `tor` (control-порт, SAFECOOKIE, bootstrap, NEWNYM, обработка
падения процесса), работа HTTP-прокси и `CONNECT`, отсутствие локального
резолвинга DNS.

### Сборка в один исполняемый файл

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name TorLocalProxy run.py
```

Папку `tor` положите рядом с готовым файлом — приложение ищет её и там.

## Если не подключается

| Симптом | Что делать |
|---|---|
| `Не найден исполняемый файл tor` | Положите Expert Bundle в папку `tor`, либо укажите путь кнопкой «Обзор…» |
| `Нет программ для транспортов: obfs4` | В папке `tor` нет `lyrebird` — распакуйте Expert Bundle целиком |
| Прогресс встал на 5–14 % | Мосты заблокированы или нерабочие. Запросите новые письмом |
| Прогресс встал на 25–75 % | Мост отвечает, но сеть режет трафик. Попробуйте `webtunnel` или `snowflake` |
| `Порт 9052 занят` | Уже запущен другой Tor. Смените порт или закройте его |
| `Трафик идёт НЕ через Tor` | Программа обошла прокси — проверьте её настройки |

Подробности всегда в `tor.log` в папке настроек.

## Что важно понимать

- Прокси слушает только `127.0.0.1`. **Не выставляйте его на `0.0.0.0`** —
  иначе ваш выход в Tor станет открытым прокси для всего интернета.
- Tor скрывает ваш IP, но **не делает вас анонимным**. Логины, куки и
  отпечаток браузера выдают вас независимо от прокси. Если задача —
  анонимный веб-сёрфинг, пользуйтесь Tor Browser: он решает и эту часть,
  а обычный браузер через прокси — нет.
- На выходном узле трафик виден в открытом виде, если сайт работает по HTTP.
  Пользуйтесь HTTPS.
- «Новая цепочка» меняет выходной узел, но не сбрасывает куки и сессии.
- Мосты — общий ресурс. Не публикуйте свои строки мостов: как только они
  становятся публичными, их блокируют.
