# TorLocalProxy 0.0.11 (Android — 0.0.9)

Клиент луковой сети с поддержкой мостов: поднимает локальный прокси (SOCKS5 и HTTP
поверх него) и уводит через сеть Tor трафик тех программ, которым этот адрес вписали.
То, что делает Tor Browser при подключении, но без браузера — только доступ к сети.

Язык — **Go** (правило 11, по согласованию: приоритетный C# уступает потому, что вся
экосистема pluggable transports написана на Go и на iOS подключается только как Go-код).

Одна кодовая база на пять систем. Различия заперты в парах файлов `runtime_*`
(где взять tor) и `platform_*` (как выжить в фоне) — подробности в `Source/ЛОГИКА.md`.

## 🧭 Что делает

1. Принимает строки мостов из письма `bridges@torproject.org` — вместе с прозой письма,
   лишнее отсеивается само.
2. Поднимает подключение к сети Tor через эти мосты, показывая прогресс 0–100 %.
3. Отдаёт наружу локальный прокси: `127.0.0.1:9050` (SOCKS5) и `127.0.0.1:8118` (HTTP)
   для программ, которые SOCKS5 не понимают.
4. Сам проверяет, вышла ли новая версия, и обновляется по кнопке.

Функционала браузера нет и не предполагается: ни окна просмотра, ни профилей,
ни защиты от отпечатков.

## 🎯 Как это работает в каждой системе

Общее везде: порты постоянные (9050 и 8118), мосты и тема сохраняются, подключение
можно поднимать само при запуске. Различия — ниже.

| | Версия | Поставка | Где лежат данные | Фон | Запуск при входе | Обновление |
|---|---|---|---|---|---|---|
| **Windows** | 0.0.11 | `.zip`, распаковать | рядом с программой | значок у часов | да | само целиком |
| **Linux** | 0.0.11 | `.deb` или `.tar.gz` | рядом (`.tar.gz`) / в профиле (`.deb`) | значок у часов | да | скачивает пакет |
| **macOS** | 0.0.11 | `.dmg` | в профиле | значок у часов | да | скачивает `.dmg` |
| **Android** | **0.0.9** | `.apk` | в песочнице приложения | служба переднего плана | нет | открывает установщик |
| **iOS** | 0.0.11 | `.ipa` через AltStore | в песочнице приложения | беззвучный звук | нет | приходит само |

### Windows

Распакованная папка самодостаточна: рядом с `TorLocalProxy.exe` лежит `tor.exe`,
устанавливать нечего. Состояние, мосты и настройки пишутся в папку `Data` рядом с
программой — в профиль пользователя не попадает ничего, папку можно носить на флешке.

**Путь к папке держать без кириллицы.** Сам tor открывает файлы однобайтовой кодировкой
и русские буквы в пути понимает не всегда: на таком пути он отвечает отказом «процесс
tor завершился, не открыв control-порт». Windows обычно выручает короткими именами 8.3,
но на части томов они отключены.

Закрытие окна крестиком прячет приложение в значок у часов, прокси продолжает отвечать.
Автозапуск — запись в `HKCU\...\CurrentVersion\Run`, без прав администратора, видна в
«Автозагрузке» диспетчера задач. Обновление проходит целиком само: скачать, сверить
сумму, подменить, перезапуститься.

### Linux

Два пакета на выбор. `.deb` ставит приложение в `/opt`, добавляет ярлык в меню и команду
`torlocalproxy`; данные при этом ложатся в `~/.config`, потому что в `/opt` обычному
пользователю писать нельзя. `.tar.gz` — то же самое без установки, и вот он переносимый:
данные лежат в `Data` рядом с программой.

tor и его библиотеки лежат внутри поставки, ставить `tor` отдельно не нужно. Сборка идёт
на Ubuntu 22.04, поэтому нужен glibc не старше её. Архитектуры две: x86_64 и arm64.

Значок в трее есть не во всякой оболочке; там, где его нет, закрытие окна означает выход.
Автозапуск — файл в `~/.config/autostart` по стандарту XDG.

### macOS

`.dmg` перетаскивается в «Программы», tor лежит внутри пакета. Пакет без подписи Apple,
поэтому первый запуск — через правую кнопку → «Открыть». Сборка пока только под Apple
Silicon.

Данные остаются в профиле (`~/Library/Preferences`), и это намеренно: «рядом с
программой» на macOS означало бы внутрь `.app`-пакета, а любой новый файл внутри ломает
его подпись — с битой подписью система приложение не запустит. Проблемы с кириллицей в
пути здесь нет: macOS работает с путями в UTF-8.

Автозапуск — агент входа в `~/Library/LaunchAgents`, виден в «Объектах входа».

### Android

**Версия здесь — 0.0.9, а не 0.0.11.** Выпуски 0.0.10 и 0.0.11 для Android отозваны:
на них владелец получал жалобы на прокси, и до выяснения причины действующей
считается последняя сборка, к которой претензий не было. Остальные системы это
не затрагивает — там 0.0.11.

В исходниках версия Android уже 0.0.12 — это **диагностическая сборка, не выпуск**.
В ней появилось то, чего не хватало при разборе: после «Bootstrapped 100%» приложение
само ходит наружу через собственный прокси и только тогда пишет ВКЛЮЧЕНО, а дальше
перепроверяет связь раз в полминуты и гасит надпись, когда трафик пропал. Весь ход
пишется в `app.log` рядом с журналом tor — файл переживает перезапуск приложения,
и по нему видно, что и когда случилось. Пока она не выпущена, свежей для телефонов
остаётся 0.0.9.

APK двух архитектур: `arm64-v8a` для телефонов, `x86_64` для эмулятора. Пакеты подписаны
отладочным ключом — обновления ставятся только пакетами с той же подписью.

Прокси, а не VPN: адрес `127.0.0.1:9050` вписывается в те приложения, которые умеют
прокси. Чтобы система не выгружала процесс, работает служба переднего плана с постоянным
уведомлением — разрешение на уведомления нужно дать при первом запуске.

Хранилище — песочница приложения, другого там и не дают; удаление приложения уносит всё
с собой. Автозапуска при входе нет: обычному приложению Android такого не позволяет.

### iOS

Ставится в обход App Store: источник AltStore/SideStore по постоянной ссылке
`https://github.com/wolf3dx/TorLocalProxy/releases/download/altstore/apps.json`,
бесплатный Apple ID, подпись живёт 7 дней и продлевается сама. Либо Sideloadly с ПК.

tor здесь не отдельный процесс, а библиотека внутри приложения: дочерние процессы в iOS
запрещены совсем. Чтобы система не усыпляла прокси в фоне, приложение проигрывает
беззвучный звук по кругу — из-за этого приёма оно и не может попасть в App Store.
Расход батареи выше обычного, и Apple вправе закрыть лазейку в любом обновлении iOS.

Хранилище — песочница приложения. Автозапуска при входе нет.

## 📦 Где выпуски

- **GitLab `vkandreevich/TorLocalProxy`** — основной репозиторий: метки `windows-v*`
  и `android-v*`.
- **GitHub `wolf3dx/TorLocalProxy`** — зеркало и единственная площадка сборки для
  Apple и Linux: метки `macos-v*`, `ios-v*`, `linux-v*` и постоянная `altstore`.

Собранные пакеты свежей версии лежат в `Release/`, прошлые — в `Release/Архив`
(на диске остаются, в репозиторий не идут). Пакеты Linux, macOS и iOS делает CI и
кладёт сразу в раздел выпусков.

## 🔧 Сборка

```bash
cd Source/app
./build-windows.sh            # .zip с tor.exe рядом
./build-android.sh arm64      # APK под телефон (amd64 — под эмулятор)
./build-linux.sh              # .deb и .tar.gz, только на Linux
./build-macos.sh              # .dmg, только на macOS
./build-ios.sh device         # .ipa, только на macOS
python manual.py              # PDF-руководство в Release/
```

Linux, macOS и iOS собираются только на своей системе — их делает CI на раннерах GitHub.
Команды сборки и тестов ядра — в `CONTRIBUTING.md`.

## ⚠️ О безопасности

Tor скрывает IP, но не делает анонимным: логины, куки и отпечаток браузера выдают
пользователя независимо от прокси. Для анонимного веб-сёрфинга нужен Tor Browser —
эта задача здесь не решается и не заявляется.

Прокси слушает только `127.0.0.1`. Выставлять его наружу нельзя: выход в Tor стал бы
открытым прокси для всего интернета.
