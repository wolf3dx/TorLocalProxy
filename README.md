# TorLocalProxy

Кросс-платформенный клиент луковой сети с поддержкой мостов: на десктопе поднимает
локальный прокси (SOCKS5 + HTTP), на мобильных работает как VPN. То, что делает Tor
Browser при подключении, но без браузера — только доступ к сети.

Язык — **Go** (правило 11, по согласованию: приоритетный C# уступает потому, что весь
экосистем pluggable transports написан на Go и на iOS подключается только как Go-код).

## 🧭 Что делает

1. Принимает строки мостов из письма `bridges@torproject.org` — вместе с прозой письма,
   лишнее отсеивается само.
2. Поднимает подключение к сети Tor через эти мосты, показывая прогресс 0–100 %.
3. Отдаёт наружу локальный прокси: SOCKS5 и HTTP поверх него для программ,
   которые SOCKS5 не понимают.

Функционала браузера нет и не предполагается: ни окна просмотра, ни профилей,
ни защиты от отпечатков.

## 🎯 Платформы

Windows x64, Linux, macOS x86_64, macOS arm64, Android, iOS — правило 9.

На десктопе это локальный прокси. На Android и iOS ОС не даёт приложению обслуживать
чужой трафик через `127.0.0.1`, поэтому там то же ядро работает как VPN
(`VpnService` и `NEPacketTunnelProvider`). Подробности — в `Source/ЛОГИКА.md`.

## ⚠️ О безопасности

Tor скрывает IP, но не делает анонимным: логины, куки и отпечаток браузера выдают
пользователя независимо от прокси. Для анонимного веб-сёрфинга нужен Tor Browser —
эта задача здесь не решается и не заявляется.

Прокси слушает только `127.0.0.1`. Выставлять его наружу нельзя: выход в Tor стал бы
открытым прокси для всего интернета.
